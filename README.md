# Abdelrahman Ahmed — Portfolio

A modern, responsive portfolio website built with Next.js, React, TypeScript, and Tailwind CSS to showcase my full-stack, backend, frontend, and AI/RAG systems projects.

## Overview

This portfolio highlights my work as a senior Computer Science student at Nile University focused on software engineering, full-stack development, and AI-integrated systems.

It showcases projects involving:

- Full-stack web applications
- Backend APIs and service integration
- AI/RAG assistants
- LLM orchestration and AI agents
- Admin dashboards and registration platforms
- Responsive user interfaces

## Featured Projects

### NUPAL — AI Academic & Career Advising Platform

An AI academic and career advising platform for Nile University students combining academic policy Q&A, semester planning, and career guidance.

Tech: Next.js, React, TypeScript, ASP.NET Core, MongoDB, FastAPI, RAG, RL, LLM orchestration.

### بَيِّنَة — Arabic RAG Islamic Assistant

Arabic-first RAG Islamic assistant frontend grounded in Qur’an, tafsir, Sunnah, and curated narrative resources.

Tech: Next.js, TypeScript, Tailwind CSS, shadcn/ui, Supabase Auth, Vercel, RTL UI, RAG.

### NUCPA — Nile University Competitive Programming Arena

Competition registration and administration platform for Nile University competitive programming activities.

Tech: Next.js, React, TypeScript, Tailwind CSS, Django, PostgreSQL, REST APIs.

## Tech Stack

- Frontend: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui
- Backend: .NET Core, ASP.NET Core, Django, FastAPI, Flask
- Databases: SQL Server, PostgreSQL, MySQL, MongoDB, Supabase
- AI/Data: RAG systems, LLM orchestration, AI agents, TensorFlow, PyTorch, Scikit-learn, Pandas, NumPy
- Tools: Git, GitHub, Docker, Postman, Vercel, Web3Forms

## Getting Started

### Prerequisites

- Node.js v18+
- npm or yarn

### Installation

```bash
git clone https://github.com/abdelrahman-a99/portfolio.git
cd portfolio
npm install
npm run dev
```

### Open:
```text
http://localhost:3000
```

## Project Structure
- `src/components/`     — Reusable UI and page sections
- `src/data/`           — Centralized profile, project, skill, and contact content
- `src/app/`            — Next.js app directory
- `public/assets/`      — Project screenshots and profile images

## Customization
Most static content is centralized in:
`src/data/index.ts`

Update this file to edit:
- Projects
- Skills
- Contact information
- Personal links
- Resume URL
- Highlight cards
